      已校準

      今天 03:15 校準：下載 486、上傳 492 Mbps，滿載時延遲多 38 ms，所以決定啟用塑型。

      校準大約需要 3 分鐘，這段時間網路會被塞滿。 線上遊戲、視訊會議可能斷線，建議沒人在用網路時再跑。會連到 Cloudflare 的測速伺服器。

        示意畫面已加速 15 倍。真實校準約 3 分鐘。

        不校準，讓 Sluice 自己學。 從線路的最高速度開始，只在有人大量使用網路時慢慢往下試探：降速後延遲變好，就停在那裡；一路降下去延遲都沒改善，代表塞車點不在你家這段線路，就把速度升回去。通常要幾天的正常使用才會穩定，這段期間效果比校準差一些。

        CPU 保護

        路由器 CPU 忙不過來時，塑型反而會讓網路變慢。開啟後，任一核心處理封包的時間超過 90% 持續 5 秒，就降一檔；CPU 回穩 10 分鐘後再試著升回一檔。如果停掉塑型後 CPU 還是滿載，或一天內第 3 次停用，就還原你原本的硬體加速設定，改成每天凌晨重試一次。
